# Todo

## Plan
Implement the library top-down starting with the most user-visible feature (EffectComposer pipeline), then adding enums, core utilities, base classes, materials, passes, effects, textures, and loaders. Each task delivers a self-contained feature with tests.

## Tasks
- [x] Task 1: Implement the EffectComposer pipeline with Pass base class and core enums. The composer manages a double-buffered render target pair (ping-pong), an ordered list of passes, and a Timer for frame timing. It provides methods to add/remove passes, render the pipeline, resize, and dispose resources. The Pass base provides a fullscreen triangle geometry, lifecycle hooks (render, initialize, setSize, dispose), and properties controlling buffer swapping, depth needs, and screen output. Include all 16 enums (BlendFunction, EffectAttribute, KernelSize, ToneMappingMode, etc.).
- [x] Task 2: Implement the Resolution manager and Selection set. Resolution tracks base dimensions, preferred dimensions, and a scale factor, computing effective size and dispatching change events. It supports auto-sizing where one dimension is computed from aspect ratio. Selection extends Set to manage three.js object visibility via render layers, supporting exclusive mode and toggling.
- [x] Task 3: Implement the GaussKernel generator and OverrideMaterialManager. GaussKernel computes discrete and GPU-optimized linear sampling weights/offsets for Gaussian blur using Pascal's triangle coefficients. OverrideMaterialManager handles scene-wide material overrides with correct handling for skinned meshes, instanced meshes, flat shading, and face culling.
- [x] Task 4: Implement the BlendMode class and Effect base class. BlendMode maps blend function enums to GLSL shader source strings and manages opacity. Effect is the base for all visual effects, storing fragment/vertex shaders, uniforms, defines, and extensions, with a change event system that triggers shader recompilation in the parent EffectPass.
- [x] Task 5: Implement the CopyMaterial shader material and CopyPass. CopyMaterial is a ShaderMaterial that copies input buffer contents with support for depth writing, channel weights, and color space conversion. CopyPass uses CopyMaterial to copy input buffer to its own render target or to screen.
- [x] Task 6: Implement ClearPass, ClearMaskPass, RenderPass, ShaderPass, LambdaPass, and MaskPass. ClearPass clears color/depth/stencil buffers with optional override clear color. ClearMaskPass disables stencil testing. RenderPass renders a three.js scene with optional material override and selection filtering. ShaderPass renders any ShaderMaterial as a fullscreen effect. LambdaPass executes an arbitrary callback. MaskPass writes a stencil mask from scene geometry.
- [x] Task 7: Implement the LuminanceMaterial and LuminancePass. LuminanceMaterial converts input to luminance values with optional threshold, smoothing, and range filtering. LuminancePass renders luminance into its own render target with configurable resolution.
- [x] Task 8: Implement EffectMaterial and the EffectPass that merges multiple effects into one shader. EffectMaterial is the compound shader material that receives composed shader parts from multiple effects. EffectPass sorts effects, prefixes their shader identifiers to avoid collisions, combines fragment/vertex code, manages depth textures, and handles per-effect blend functions.
- [x] Task 9: Implement simple color effects: BrightnessContrastEffect, SepiaEffect, ColorAverageEffect, ColorDepthEffect, GammaCorrectionEffect, HueSaturationEffect. These are simple fragment shader effects that modify pixel colors using uniform parameters.
- [x] Task 10: Implement pattern and screen effects: NoiseEffect, VignetteEffect, DotScreenEffect, GridEffect, ScanlineEffect, PixelationEffect. These effects add visual patterns, noise, or modify screen resolution.
- [x] Task 11: Implement blur passes: BoxBlurPass, GaussianBlurPass, KawaseBlurPass, MipmapBlurPass, and TiltShiftBlurPass. These provide various blur algorithms with ping-pong rendering, configurable kernel sizes, and resolution scaling.
- [x] Task 12: Implement the BloomEffect and SelectiveBloomEffect. BloomEffect extracts bright areas using a luminance pass, blurs them with mipmap or Kawase blur, and adds the glow back. SelectiveBloomEffect extends this with object selection via render layers.
- [x] Task 13: Implement depth-related passes and effects: DepthPass, DepthCopyPass, DepthPickingPass, NormalPass, and DepthEffect. These render scene depth/normals into textures and provide depth reading capabilities.
- [x] Task 14: Implement the ToneMappingEffect with adaptive luminance. This effect supports multiple tone mapping modes (Linear, Reinhard, ACES, AGX, etc.) and an adaptive mode that adjusts exposure based on scene luminance over time.
- [x] Task 15: Implement texture utilities: RawImageData, NoiseTexture, and TextureEffect. RawImageData wraps raw pixel data. NoiseTexture generates procedural noise. TextureEffect overlays a texture with UV transforms and aspect correction.
- [ ] Task 16: Implement LUT texture support: LookupTexture with tetrahedral interpolation upscaling, and LUT file loaders (LUT3dlLoader and LUTCubeLoader). Users can load .3dl and .cube color grading files and apply them as 3D lookup textures.
- [ ] Task 17: Implement advanced effects: ChromaticAberrationEffect, LensDistortionEffect, GlitchEffect, ShockWaveEffect, FXAAEffect, and ASCIIEffect. These are more complex visual effects involving screen-space distortion, temporal animation, and anti-aliasing.
- [ ] Task 18: Implement outline and SSAO effects: OutlineEffect and SSAOEffect. OutlineEffect renders object outlines using edge detection. SSAOEffect computes screen-space ambient occlusion.
- [ ] Task 19: Implement remaining effects and passes: GodRaysEffect, BokehEffect, RealisticBokehEffect, DepthOfFieldEffect, TiltShiftEffect, LUT1DEffect, LUT3DEffect, SMAAEffect. Also implement SMAAImageLoader and SMAA image generation utilities.
- [ ] Task 20: Implement remaining materials, additional passes, and the main index entry point. Create the AdaptiveLuminanceMaterial/Pass, DepthDownsamplingPass, and all remaining shader materials. Wire up the complete public API through the main index.
